Privacy Policy: ResolveAI Studio

Last updated: 15 November 2026

ResolveAI Studio is a private tool used only by ResolveAI to publish its own videos to its own YouTube channel and Instagram account. It has no other users and collects no personal data from anyone.

ResolveAI Studio uses YouTube API Services to upload videos. By using it, you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

What it accesses: only the ResolveAI YouTube channel (to upload videos, set thumbnails and delete its own test uploads) and the ResolveAI Instagram account (to publish Reels). The access token is stored encrypted in GitHub Secrets and is never shared, sold or used for anything else.

Access can be revoked at any time at Google security settings. To delete the stored token, the owner removes it from the repository's GitHub Secrets.

ResolveAI Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
